# Contributing to NextPills

Thank you for your interest in contributing to **NextPills**!

---

## 🛠️ Development Setup

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/NextPills.git
   cd NextPills
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npx expo start
   ```

---

## 📋 Guidelines

- **Privacy-First Mandate**: NextPills is strictly a **100% offline app**. No PR introducing external network dependencies, analytics SDKs, or cloud backends will be accepted.
- **Code Style**: Keep code clean, functional, and well-organized following existing Expo Router conventions.
- **Branch Naming**: Use descriptive branch names like `feat/sound-customization` or `fix/snooze-trigger`.

---

## 🐛 Reporting Bugs

Open an issue on GitHub with:
- Clear description of the bug
- Device model and Android / iOS version
- Steps to reproduce
